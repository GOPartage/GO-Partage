📁 Importer un nouvel album

Importe un fichier JSON : nom, saison, collections et 9 cartes par collection. L’album sera ajouté sans remplacer l’album actif. Tu pourras l’activer lorsqu’il sera complet (23 collections / 207 cartes).

Aucun fichier sélectionné.

Voir le format attendu du fichier 
{
  "name": "Nom de l’album",
  "season": "Saison",
  "sets": [
    {
      "name": "Nom de la collection",
      "name_fr": "Nom français (facultatif)",
      "cards": [
        {
          "card_number": 1,
          "name": "Nom de la carte",
          "name_fr": "Nom français (facultatif)",
          "rarity": "4 étoiles",
          "is_gold": false,
          "is_tradable_now": true
        }
      ]
    }
  ]
}
